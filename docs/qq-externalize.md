# qq-externalize

**The problem:** You ask Claude to research a topic, summarize a document, critique a plan, give a second opinion. Claude does it, and bills your subscription. A free model would have done it for nothing.

**The result:** Free models handle 70%+ of non-synthesis work. Claude stays for judgment and synthesis, where it's actually worth paying for.

## Commands

```
/qq-externalize              — audit current task, produce routing plan, execute
/qq-externalize [task]       — route a specific task to the right free model
/qq-externalize adversarial  — cross-model adversarial pass on what's in context
```

Full model setup, routing card, and install steps: [repo README → qq-externalize](https://github.com/lee-fuhr/claude-operator-skills#qq-externalize).
