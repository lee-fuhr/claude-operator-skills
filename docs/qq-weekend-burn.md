# qq-weekend-burn

**The value:** A Claude subscription resets its quota every week whether you used it or not. Driving a long autonomous session yourself, every Saturday, forever, isn't something you actually do by hand.

**The result:** Install it and walk away. It fires itself inside a recurring window you choose, works one real capability at a time to an actual finished state, and stands down the moment you're back at the keyboard.

## How to invoke it

Deterministic, not a phrase Claude has to guess at: run `/qq-weekend-burn`. It scaffolds every file the schedule needs and hands you a one-paste block to install the actual recurring trigger.

Built on `keepalive` (also in this repo) for session survival across caps, closed laptops, and reboots.

Full feature list, key principles, and install steps: [repo README → qq-weekend-burn](https://github.com/lee-fuhr/claude-operator-skills#qq-weekend-burn).
