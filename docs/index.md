Skills built to run a real Claude Code setup, not a generic starter pack. Full install instructions and detail live in the [repo README](https://github.com/lee-fuhr/claude-operator-skills).

## The six skills

- **[qq-externalize](qq-externalize/)**: routes research, extraction, and critique to free models. Claude synthesizes only.
- **[qq-smart-next-move](qq-smart-next-move/)**: surfaces the smart next move while you're still in flow.
- **[qq-audit](qq-audit/)**: 255 expert-persona audit frameworks across 13 quality domains, smart-routed.
- **[qq-weekend-burn](qq-weekend-burn/)**: a recurring schedule that burns unused quota on real work every week.
- **[copy-sweep](copy-sweep/)**: blocks AI-tell punctuation before it lands in a file.
- **[qq-mailbox](qq-mailbox/)**: coordination primitive for two or more concurrent Claude sessions.

Each page links back to its skill's implementation and install steps in the main repo.
