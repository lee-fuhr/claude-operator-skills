# QUESTIONS-FOR-YOU.md format template

The fill-in-the-blank scaffold for the file described in SKILL.md’s QUESTIONS-FOR-YOU protocol.

### Format

```markdown
# Questions for you

*Generated: [date] during overnight session*

---

## Needs answer before proceeding

### Q1: [Topic]
**Context:** [What agent was doing, what triggered the question]
**Options:**
- A: [option with tradeoff]
- B: [option with tradeoff]
**Default if no answer by morning:** [what agent will do / what will be skipped]
**Blocks:** [Task X, Task Y]

---

## FYI / decisions made autonomously

### D1: [Topic]
**Decision:** [What was chosen]
**Rationale:** [Why]
**Reversible?** Yes / No
```
