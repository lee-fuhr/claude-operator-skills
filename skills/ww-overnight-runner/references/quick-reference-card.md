# Quick reference card

A condensed checklist covering the full overnight session lifecycle, gathering items already detailed in SKILL.md’s own checklists into one scannable card.

## Quick reference card

```
OVERNIGHT SESSION CHECKLIST

PRE-FLIGHT
[ ] Work queue written with priorities
[ ] tonight-results.md created
[ ] Status board created, URL saved somewhere you'll see it
[ ] QUESTIONS-FOR-YOU.md path established
[ ] Hard stops documented ("don't X")
[ ] Results file open in your markdown viewer of choice

DURING
[ ] Steelman every plan before execution
[ ] Park blocking questions (don't guess on irreversible)
[ ] Log every autonomous decision
[ ] Checkpoint after each task
[ ] Never parallelize same-file writes

POST-TASK (each task)
[ ] Read output — does it match success criterion?
[ ] Run tests if applicable
[ ] Append result to results file
[ ] Note anything needing your review

ON SESSION RESUME (after compaction)
[ ] Read results file — this is ground truth, not in-session task state
[ ] Identify completed tasks (have result entries) vs. pending
[ ] Check the status board for any post-compaction updates
[ ] Resume from first unfinished task

MORNING HANDOFF
[ ] Results file shows task-by-task status
[ ] Status board reflects final state
[ ] QUESTIONS-FOR-YOU.md has open questions
[ ] "Suggested first action" is clear
[ ] Any commits are staged but not pushed
```
